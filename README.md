Игра **«Камень, ножницы, бумага» на МИК32 АМУР** с нейросетевым соперником. Игрок входит по RFID-карте и выбирает ход одной из трёх кнопок. Устройство показывает результат на LCD, воспроизводит мелодии и сохраняет статистику в EEPROM.

Нейросеть предсказывает следующий ход по истории игрока, а устройство выбирает контрход. Модель обучена на компьютере и выполняется на микроконтроллере с весами `int8`.

## Возможности

- Игровой интерфейс на LCD 16×2: меню, отсчёт, показ ходов и результата.
- Вход по RFID-карте и переключение между игроками.
- До 16 профилей со статистикой раундов, побед, ничьих и поражений.
- Сохранение статистики и истории модели в EEPROM с проверкой CRC32.
- Звуковое сопровождение и журнал событий через UART.

## Управление

1. Приложите RFID-карту, чтобы загрузить профиль или создать новый.
2. Нажмите кнопку «камень», «бумага» или «ножницы» и дождитесь результата.
3. В ожидании следующего хода приложите свою карту повторно, чтобы сохранить сессию и вернуться в меню. Другая карта сохраняет текущую сессию и переключает игрока.

В меню кнопки «камень» и «ножницы» перемещают по списку профилей, а «бумага» возвращает к первой записи.

## Аппаратная часть

Прошивка рассчитана на МИК32 АМУР / MIK32V2 с частотой 32 МГц и внешней SPI Flash. Программа размещена в памяти SPIFI с адреса `0x80000000`.

| Компонент | Подключение |
| --- | --- |
| MFRC522 / RC522 | `SPI0`, CS — `P0.8`, RST — `P0.10`. |
| LCD 16×2 с I²C-адаптером | `I2C1`, адрес `0x27`. |
| Кнопка «камень» | `P1.8`. |
| Кнопка «бумага» | `P1.9`. |
| Кнопка «ножницы» | `P1.2`. |
| Пассивный зуммер | PWM, `TIMER32_2`, канал 1. |
| UART | USART0, 115200 бод. |

Кнопки замыкаются на GND и используют внутреннюю подтяжку вверх. Для загрузки прошивки используется Mikron-Link / FTDI.

## Нейросеть

MLP получает историю шести раундов. Каждый раунд кодируется двумя one-hot векторами: ходом игрока и результатом. Выход модели определяет наиболее вероятный следующий ход.

| Параметр | Значение |
| --- | --- |
| Архитектура | `36 → 16 → 3`, ReLU. |
| Веса и смещения | `int8`, 643 байта. |
| Промежуточные вычисления | `int32`, `SCALE = 64`, `SHIFT = 6`. |
| Точность на синтетической тестовой выборке | 62,67%. |

## Сборка и прошивка

### Требования

- Git, Docker и VS Code с расширением Dev Containers.
- Для загрузки — плата и отладчик Mikron-Link.

Окружение [Dev Container](.devcontainer/Dockerfile) содержит CMake, Ninja, RISC-V GCC 14.2.0, OpenOCD и Ceedling 1.0.1.

```sh
git clone --recurse-submodules https://github.com/DafterT/mic32-final-project.git mik32-rps
cd mik32-rps
```

Откройте проект в VS Code и выполните **Dev Containers: Reopen in Container**. В терминале контейнера:

```sh
make build_app    # сборка
make flash        # загрузка прошивки
make monitor      # UART
```

| Файл | Назначение |
| --- | --- |
| `build/firmware/mik32-rps.hex` | Прошивка для загрузки через `mik32-uploader`. |
| `build/firmware/mik32-rps.bin` | Двоичный образ. |
| `build/firmware/mik32-rps.elf` | ELF с отладочными символами. |

[Настройка USB в Windows и отладка](docs/development.md).

## Тесты

```sh
make test
make coverage_report
```

Модульные тесты Ceedling проверяют игровую логику, автомат состояний интерфейса, хранение профилей, CRC, хеширование UID и целочисленную модель. Тесты выполняются на компьютере с подменным backend хранилища.
